Project Overview

Morgan's Café is a local café website created as part of the WEDE5020 Web Development (Introduction) project. The website is designed to give customers information about the café, its products, contact details and enquiry options. The website provides a simple and welcoming online presence for Morgan's Café. It allows visitors to move between the different pages using a consistent navigation menu and find information about the café and the products it offers. The website has been developed using HTML and organised into separate folders for CSS, JavaScript and images.

Website Goals and Objectives

The main goals of the Morgan's Café website are to: Create a professional online presence for the café. Provide customers with information about the café. Display the food and drinks available at Morgan's Café. Make it easy for visitors to find contact information. Allow customers to make enquiries through the website. Provide simple and clear navigation between the website pages. Create a welcoming design that matches the atmosphere of the café.

Target Audience

The main target audience includes: Local customers looking for food and drinks. Students and young adults. People looking for a place to relax or meet friends. Customers interested in coffee, meals, desserts and cold drinks. Existing customers who need contact or enquiry information.

Website Pages

The website contains five main pages: Home – Introduces Morgan's Café and provides an overview of the café. About Us – Provides information about the café, including its story, mission, vision and target audience. Products – Displays the café's food and drink offerings and prices. Inquiry – Allows customers to submit an enquiry about the café. Contact – Provides contact information, opening hours, branches and a contact form. Key Features and Functionality The main features included in the website are: Consistent navigation menu across the pages. Home page with a hero section and café introduction. Call-to-action buttons such as "View Menu" and "Make an Enquiry". About Us page containing the café's story, mission and vision. Products page containing food and drink categories and prices. Enquiry form containing customer information and enquiry fields. Contact page containing contact information and a contact form. Images organised into separate folders. CSS stylesheet used for the website design. Organised project folders for CSS, JavaScript and images. A promotional coffee video created by combining sourced media using CapCut.
